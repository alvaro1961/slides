Machine Learning from First Principles

The core ideas behind modern AI are not new. Most of them were worked out by statisticians over the past century: fitting curves, estimating probabilities, controlling for overfitting.


These presentations focus on the ideas that matter most: the small set of concepts that explain most of what modern ML does. The first presentations use R, the natural language of statistics. Later ones move to Python, where the math and code becomes more explicit.

Statistical Foundations
1

Regression Models

Open ↗

Fitting a function to data by minimizing prediction error is central to statistics — and equally central to machine learning, where the same idea scales to more powerful models and larger datasets.

Model capacity: A more flexible model fits training data better, but may generalize worse. Watching error on held-out data reveals where that line is.
Bias–variance tradeoff: Simple models err by being wrong on average (bias); complex ones err by being inconsistent (variance). Neither extreme is good.
Train / validation / test splits: Training error tells you about fit, not about generalization. Train/validation/test splits exist to measure what actually matters: how the model performs on new data.
2

Classification & Maximum Likelihood

Open ↗

When the outcome is a category, statistics works with probabilities rather than continuous predictions — and so does machine learning, where the same probabilistic framework extends to neural networks and beyond.

Maximum likelihood estimation: Instead of minimizing squared error, we choose parameters that make the observed labels most probable. This is the foundation of almost every loss function in ML.
Cross-entropy loss: Minimizing cross-entropy and maximizing likelihood are the same thing. Binary cross-entropy handles the two-class case; softmax cross-entropy generalizes it to any number of classes by turning raw scores into a probability distribution.
Precision, recall, and class imbalance: Not all errors cost the same. When classes are imbalanced, precision and recall let you control the tradeoff between false alarms and missed detections.
3

High-Dimensional Classification

Open ↗

High-dimensional inputs like images expose real limits of standard classification. The fixes — regularization and dimensionality reduction — are classical ideas that remain central to modern ML.

Images as data: Pixels are just numbers, and a small image already has hundreds of them. Treating each one as a feature makes the input space enormous by default.
The curse of dimensionality: With hundreds of features, logistic regression produces extreme, unstable coefficients — overconfident on training data and brittle on new inputs.
Regularization and dimensionality reduction: Two complementary fixes. Regularization shrinks coefficients directly; PCA first compresses the input by finding the directions that capture most of the variance, discarding the rest.

Neural Networks

Open ↗

Regression and classification revisited in R with a more flexible model class — networks of stacked linear transformations and nonlinear activations that can approximate functions no polynomial or logistic model could fit.

Function composition and activation: Stacking linear layers with non-linear activations produces models that can approximate any continuous function
More capacity, more risk: A network with enough parameters can fit any training data perfectly. That makes overfitting not just possible but the default. Controlling it requires careful model selection, regularization, and validation.
5

Neural Networks in PyTorch

Open ↗

The same networks, now implemented in PyTorch. Automatic differentiation is introduced, and the training loop — forward pass, loss, backward pass, parameter update — becomes explicit and reusable.

Autodiff and computation graphs: PyTorch tracks every operation so it can differentiate through them automatically — no hand-derived gradients needed.
Training loop anatomy: Forward pass, loss, backward pass, optimizer step. Everything in a neural network framework maps back to these four moves.

Kernel Methods & RKHS (possible addition)

The other path to non-linearity — and the dominant approach before deep learning.

The kernel trick: Map inputs to a high-dimensional space implicitly, without ever computing the coordinates — then apply linear methods there.
Support vector machines and RKHS: SVMs were state of the art in the 2000s. Understanding them shows that neural networks aren't the only way to learn non-linear boundaries.
Convolutional Neural Networks
7

Images as Data

Open ↗

The first step toward understanding CNNs is representing images as arrays of numbers and using linear algebra to transform them.

Images as arrays: A grayscale image is a 2D matrix of pixel values; a color image is a 3D array with one channel per color. Every operation on an image is an operation on numbers.
Reshaping and indexing: Working with images requires fluency with array manipulation — flattening, slicing, and reshaping between 2D and 3D. These skills are essential for everything that follows.
Linear transformations on images: Color swaps, grayscale conversion, and sepia filters are all matrix multiplications. Linear algebra is not just theoretical — it acts directly on image data.
8

Convolutions and Filters

Open ↗

A convolution is a linear map on arrays. Classical hand-designed kernels — edge detection, blurring, sharpening — illustrate the operation that CNNs later learn from data.

Convolution as a linear map: A kernel slides across an input array, computing a weighted local sum at each position.
4D tensors in PyTorch: Images and kernels require four dimensions — batch, channels, height, width. The spatial operation is unchanged; the extra dimensions handle multiple images and multiple input/output channels simultaneously.
Stride, dilation, and channels: Stride downsamples the output; dilation expands the receptive field without adding parameters. Applying N filters to a C-channel input produces N output channels — the core operation repeated at every layer of a CNN.
6

Convolutional Neural Networks

Planned

Fixing the spatial blindness of flattened inputs with locally connected, weight-shared filters.

The problem with flattening images: A pixel's meaning depends on its neighbors. Flattening destroys that structure. Convolutions preserve it.
Translation invariance: The same filter applied at every position means a detector for a feature in the top-left also works in the bottom-right — far more efficient than learning both separately.
